# Pokémon New Age

Un jeu Pokémon fan-made en 3D réaliste, fait avec **Unreal Engine 5**.

La première version recrée une région Pokémon existante (Kanto) en 3D : on explore, on combat, on capture, on remplit le Pokédex, on bat les champions d'arène et on fait monter ses Pokémon de niveau.

## Prérequis

- Unreal Engine 5 (via l'Epic Games Launcher)
- Visual Studio 2022 avec la charge de travail « Développement de jeux en C++ » (nécessaire pour compiler le C++ d'Unreal sous Windows)
- Visual Studio Code comme éditeur de code
- Git et **Git LFS** : lancer `git lfs install` une fois avant de cloner

## Démarrer

1. `git lfs install`
2. `git clone https://github.com/rxfwn/pokemonnewage.git`
3. Ouvrir le fichier `.uproject` avec Unreal Engine 5 (il sera ajouté au sprint 0, voir [docs/CREER_PROJET_UE5.md](docs/CREER_PROJET_UE5.md)).

## Organisation

On travaille en sprints de deux semaines. Le backlog complet est dans [docs/BACKLOG.md](docs/BACKLOG.md), les conventions de nommage dans [docs/CONVENTIONS.md](docs/CONVENTIONS.md), la configuration de VS Code dans [docs/CONFIGURER_VSCODE.md](docs/CONFIGURER_VSCODE.md).
